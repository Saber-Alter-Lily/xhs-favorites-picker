# XHS Favorites Picker

一个本地运行的小红书收藏挑选、图片保存和阅读工具。

**把收藏夹里真正想留下的内容，挑出来保存到电脑。**

## 功能

- 浏览和同步“我的收藏”
- 多选作品批量保存图片
- 粘贴分享链接快速保存
- 本地阅读已下载内容
- 按作者查看作品
- 订阅作者，只提示后续新增内容
- 兼容 v0.4 / v0.5 的旧 `downloads/` 仓库

## 安装

支持 **Windows 10/11**。

需要：

- Google Chrome
- Python 3.10+
- Node.js 22+

下载最新版本并解压，第一次运行：

```text
setup.bat
```

按提示登录一次小红书。

以后直接运行：

```text
run.bat
```

## 使用

### 我的收藏
选择想保存的作品，然后下载。需要更新收藏时点 **“同步收藏”**。

### 快速保存
粘贴小红书分享文案或链接，解析后直接保存。

### 本地阅读
打开 **“本地阅读”** 查看 `downloads/` 中已经保存的作品和图片。

### 作者订阅
进入作者页面后可以订阅，只检查后续新增内容，不会默认下载全部历史作品。

## 从 v0.4 / v0.5 升级

**不要删除旧目录。**

关闭旧程序，解压新版，运行：

```text
upgrade_from_v04_v05.bat
```

选择旧安装目录即可。

旧的图片、登录状态、订阅和缓存都会保留，不需要重新下载。

## 数据位置

主要数据都保存在程序目录：

```text
downloads/                  已下载图片
.redbook-cookies.json       登录状态
.chrome-debug-profile/      专用 Chrome 登录配置
.subscriptions.json         作者订阅状态
.favorites-cache.json       收藏缓存
```

**不要把 Cookie 文件或 Chrome Profile 分享给别人。**
